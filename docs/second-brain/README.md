## Güncelleme kuralı

Her çalışma sonunda NOW.md'ye yapılanı, çalıştırılan doğrulamayı, kanıt yolunu ve sonraki somut adımı yaz. Görev ancak kendi KABUL koşulları sağlanınca tamamlanmış sayılır. ClickUp durumu ile yerel uygulama durumu ayrı tutulur; bu dizine yazmak ClickUp'ı güncellemez.

- `[V]`: doğrudan doğrulandı; kanıt belirt.
- `[NV]`: henüz doğrulanmadı; eski raporun iddiasını yeni test gibi sunma.
- `[ASSUMPTION]`: çalışma varsayımı.
- Anahtar, parola, e-posta, ham API yanıtı ve büyük bilimsel veriyi buraya koyma.
- Aynı bilgiyi yeniden kopyalamak yerine asıl belgeye bağlantı ver.
