## Propagation (standard; NOT VERIFIED on a page)
- Simple linear: dt = T - 2016.0 (yr); ra(T)=ra + pmra*dt/(3.6e6*cos(dec)) (pmra already includes cos dec, mas/yr); dec(T)=dec + pmdec*dt/3.6e6. Fine for small dt, small FOV.
- Caveat: high-PM/near stars: use full space-motion rigorous propagation (needs parallax + radial_velocity; astropy SkyCoord.apply_space_motion / Gaia's own recipe); RV often null (use 0); parallax null for 2-param sources (no pm either: pmra null -> no motion); don't use negative/noisy parallax; plx-based annual parallax shift not in simple formula. WiseView ignores RV; draws parallax as circle radius.

## WiseView [VERIFIED from page: http://byw.tools/wiseview and http://byw.tools/static/flash3.js]
- Page relative script is static/flash3.js => served at http://byw.tools/static/flash3.js (open source in the sense of readable JS; no GitHub link found on the page). Page credits: American Museum of Natural History; unWISE (unwise.me); links to Legacy Survey viewer, Simbad, Vizier, PS1 cutouts, Zooniverse (Backyard Worlds).
- State lives in URL HASH (#), not query: window.location.hash = jQuery.param(args). Params: ra, dec, size (arcsec, max 2000, default 176), band (1=W1,2=W2,3=W1+W2), speed (blink ms, default 500), minbright, maxbright (default -50 / 500 "px"), window (yrs, default 0.5), diff_window (yrs, default 1.0), linear (stretch 0..1, default 1.0), color, zoom, border(0/1), gaia(0/1), invert(default 1), maxdyr, scandir, neowise, diff, outer_epochs, unique_window(default 1), smooth_scan, shift, pmra, pmdec (mas/yr), synth_a/synth_b + _sub,_ra,_dec,_w1,_w2,_pmra,_pmdec,_mjd. Default location 133.786245 -7.244372. Coords accept decimal or sexagesimal.
- Example: http://byw.tools/wiseview#ra=133.786245&dec=-7.244372&size=176&band=2&speed=500&window=0.5&diff=1&gaia=1
- Backend: the page calls an AWS Lambda/API gateway https://moo23y1au0.execute-api.us-west-2.amazonaws.com/default/png-animation with ra,dec,band,size,min/maxbright,invert,stretch,diff,scandir,outer,neowise,window,diff_window,unique,smooth_scan,shift,pmx,pmy(=pm/1000/2.75 px/yr),synth_*; returns JSON meta: ims (PNG paths under https://amnh-citsci-public.s3-us-west-2.amazonaws.com/), all_mjds, mjds, epochs, neg_epochs, min,max, FITS WCS CRPIX/CRVAL/NAXIS. So frames are SERVER-RENDERED PNGs of unWISE time-resolved coadds (not computed in browser). Browser only cycles <img> with setInterval(frame, speed).
- Image/ diff semantics (Help text + tooltips): sliding window coadds epochs within window; diff = (sum in window) - (sum outside window); "+ - ." epoch legend beside images; dashed white border on epoch 0 to show loop restart; separate scan directions shown sequentially; NEOWISE-only; skip middle epochs; skip duplicate windows; smooth by scan direction; arcsinh stretch with linearity slider; invert; click image to recentre; click-drag opens new tab with new FOV; W1+W2 color: red=W2, blue=W1, green=avg. Pixel scale 2.75"/px.
- Gaia overlay (query_gaia, client side): fetch Gaia sources in circle radius (size/3600*2.75 deg -- note: size*2.75 factor looks like it is oversized), draw per blink frame on hidden canvas -> ImageData per frame: green circle at position propagated to the frame's mean MJD, radius max(0.1, parallax/50) px-scale, plus line from position at first to last frame epoch. Propagation: px += ((base_mjd - mjd)/365.25)*(pmra/1000/2.75) with base_mjd=57204 (=2015.5, the DR2 epoch) even though query is gaiadr3 (ref epoch 2016.0 = MJD 57388) -> ~0.5 yr (<=0.5*pm) inconsistency; copy but use 57388. Note sign: px uses +pmra (x pixel direction depends on WCS handling in __world_to_pix; East-left images -> verify).
- Shift & add: pmra/pmdec shift images before coadd (server-side).
- Synthetic objects A/B: add/subtract fake source with W1,W2 mag, pm, ref MJD at ra/dec.
- v1 URL compat via v1UrlCompat; wiseview-v3 exists at /wiseview-v3#...
