Comet 3I/ATLAS

|  |  |
| --- | --- |
|  | SPHEREx observations of Comet 3I/ATLAS |

|  |
| --- |
| SPHEREx observed the [interstellar comet 3I/ATLAS](https://science.nasa.gov/solar-system/comets/3i-atlas/) in August and December 2025. The calibrated spectral images are available through IRSA, alongside all other [SPHEREx mission data](https://irsa.ipac.caltech.edu/Missions/spherex.html). This page provides resources that help you find, view, and work with SPHEREx observations of Comet 3I/ATLAS.   Identify and visualize SPHEREx observations of 3I/ATLAS   A table listing all SPHEREx observations of 3I/ATLAS is available to aid browsing and visualization. For each spectral image, the table provides a URL for access, the predicted sky position of 3I/ATLAS for the exposure (comet\_ra, comet\_dec), and other metadata.  You can upload this table into the [IRSA Viewer web application](https://irsa.ipac.caltech.edu/irsaviewer/), which will interactively display each observation. You can also read the table into your programming language of choice to create [cutouts](https://irsa.ipac.caltech.edu/data/SPHEREx/docs/cutout_tool.html) or custom visualizations.  Note: SPHEREx observations of 3I/ATLAS have low signal-to-noise at many wavelengths. See the SPHEREx publications below for details on data quality and interpretation.  Download the [observation table](obscore_3I_Atlas.vot) (VO Table format). Download scripts Scripts are available to download all calibrated SPHEREx image files that include 3I/ATLAS. One uses wget and another uses curl, so you can choose the version that works best for your system. These scripts retrieve the full set of calibrated image products for offline analysis. Download the scripts:   * [wget script](3IATLASImages-wget.sh) * [curl script](3IATLASImages-curl.sh)  Photometry guidance At the resolution of SPHEREx, 3I/ATLAS is spatially extended at many wavelengths (see the publications below). Because of this, we do not recommend using the SPHEREx Spectrophotometry Tool, which is designed for point-like or nearly point-like sources. Related SPHEREx publications  1.
