SPHEREx: An All-Sky Spectral Survey
===================================

### Mission Characteristics

|  |  |
| --- | --- |
| **Lifetime:** | 2025 - 2027 (planned) |
| **Wavelength:** | 0.75-1.1 microns, R=39  1.1-1.6 microns, R=41  1.6-2.4 microns, R=41  2.4-3.8 microns, R=35  3.8-4.4 microns, R=112  4.4-5.0 microns, R=128 |
| **Area Coverage (planned):** | 100% of sky |
| **Instruments:** | Wide Field Linear Variable Filter (LVF) Imaging Spectrograph |
| **Funding Agency:** | NASA |
| **Contributing Institutions:** | JPL, Caltech, RIT, Harvard/CFA, Arizona State, University of Arizona, Ohio State University, KASI, UC Irvine, Johns Hopkins, ASIAA |
| **Acknowledgement:** | Please include the following acknowledgement in any published material that makes use of SPHEREx data products: *"This publication makes use of data products from the Spectro-Photometer for the History of the Universe, Epoch of Reionization and Ices Explorer (SPHEREx), which is a joint project of the Jet Propulsion Laboratory and the California Institute of Technology, and is funded by the National Aeronautics and Space Administration."* |
| **Canonical Papers:** | Mission: [Bock et al (2026)](https://ui.adsabs.harvard.edu/abs/2026ApJ...999..139B/abstract)  Pipeline: [Akeson et al (2026)](https://ui.adsabs.harvard.edu/abs/2026ApJS..285...67A/abstract)  Sky Simulator: [Crill et al. (2025)](https://ui.adsabs.harvard.edu/abs/2025ApJS..281...10C/abstract)  Instrument & Calibration: [Korngut et al. (2026)](https://ui.adsabs.harvard.edu/abs/2026arXiv260329835K/abstract) |
| **SPHEREx Releases:** | July 2025: [First Quick Release Products available at IRSA](/data/SPHEREx/docs/overview_qr.html)  October 2025: [First reprocessed Quick Release Products (QR2) available at IRSA](/data/SPHEREx/docs/overview_qr.html)  April 10, 2026: [QR2 headers updated to correct PSF extension header error (see documentation for details)](/data/SPHEREx/docs/psfhdrerr.html)  September 2026: [First Quick Release 3 (QR3) Products available at IRSA](/data/SPHEREx/docs/overview_qr.html)  November 2026: [Data Release 1 (DR1) Products available at IRSA](/data/SPHEREx/docs/overview_dr1.html) |

### SPHEREx Science Tools

|  |  |
| --- | --- |
| [Spectrophotometry Tool](/applications/spherex/tool-spectrophotometry) | Extract spectra from SPHEREx Spectral Images using forced photometry. Read the [Spectrophotometry Tool documentation](/onlinehelp/spherex/#sp) for detailed usage instructions, inputs, and outputs. |
| [Mosaic Tool](/applications/spherex/tool-mosaic) | Create custom multiwavelength mosaics from SPHEREx Spectral Images. |
| [Cutout Tool](/data/SPHEREx/docs/cutout_tool.html) | Extract spatial subsets from SPHEREx Spectral Image Multi-Extension FITS files. |
| [Source Discovery Tool](https://caltech-ipac.github.io/irsa-tutorials/spherex-source-discovery-tool-demo/) | Identify and characterize significant detected sources within a user defined region using SPHEREx data alone, without requiring positional priors. |
