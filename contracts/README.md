# Sözleşmeler (alanlar arası arayüzler)

Burada alanlar arasındaki anlaşmalar durur: kare ürün dosyası biçimleri ve manifest şeması (02-10, 02-11), API sözleşmesi `openapi.yaml` ve sahte sunucu (06-14), URL parametre şeması (05-10, 05-18). Bir sözleşme değişirse sürüm numarası artar ve ilgili alanların sahipleri onaylar (CODEOWNERS'ta üç alan birlikte).
