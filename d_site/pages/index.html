Scientific Integrity & Provenance Rules (W22 / 10-16)

  • Direct NASA S3 L2 FITS Cutouts [V: s0_B, s0_C]: Barnard's Star frames are verbatim 31×31 float32 cutouts from s3://nasa-irsa-spherex/dr1/level2/ (IMAGE, VARIANCE, ZODI, 3rd-order TAN-SIP WCS).
  • Saturated Cores [V: s0_B]: Barnard's Star has a 2×2 NaN saturated core (rendered in Okabe-Ito blue #0072B2) and is measured via inverse-variance weighted PSF wing fitting.
  • No Drizzle / No AI Upscaling [V: 00-01, 00-02]: Display operations run on a copy; sub-pixel coordinates are never rounded.

Keyboard Shortcuts & Quick Guide (10-10)

All viewer operations can be controlled from the keyboard or mouse:

  • Space : Play / Pause automatic time-series blink
  • ← / → : Step backward / forward one epoch
  • [ / ] : Slower / Faster blink interval
  • G : Toggle native pixel grid lines
  • I : Toggle inverted grayscale colormap
  • O : Toggle Gaia DR3 catalog overlay
  • R : Restart blink sequence to Pass 1
  • Click Canvas : Pin / unpin pixel in the sub-pixel inspector
